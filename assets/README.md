# Assets

Drop future binary/static assets here instead of relying on external CDN URLs.

- /textures  - image/canvas-baked textures (leaf, moon, flower, etc. once moved off procedural canvas gen, or any hand-authored textures)
- /audio     - ambient loops, sfx (day/night ambience, wind, water, rain, footsteps)
- /models    - glTF/.glb assets (planned: low-poly buildings for Another Sky, any imported meshes for Silvan)
